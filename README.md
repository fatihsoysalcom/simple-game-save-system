# Simple Game Save System

This Python script demonstrates a basic game save system. It allows saving the current game state (player level, XP, inventory, location) to a JSON file and loading it back, ensuring progress is not lost.

## Language

`python`

## How to Run

Run the script using: python save_system.py. It will create a 'savegame.json' file.
